## 📖 Описание

**GitHub User Finder** – это десктопное приложение с графическим интерфейсом (GUI) для поиска пользователей GitHub через официальное REST API. Приложение позволяет быстро находить пользователей по логину, просматривать результаты, добавлять понравившихся пользователей в «Избранное» и сохранять этот список локально в JSON-файл.

### Основные возможности:
- Поиск пользователей GitHub по частичному или полному совпадению логина.
- Отображение списка найденных пользователей.
- Добавление пользователей в избранное (сохраняется в файл `favorites.json`).
- Удаление пользователей из избранного.
- Автоматическое восстановление избранного при следующем запуске.
- Валидация ввода: поле поиска не может быть пустым.
- Обработка ошибок сети и некорректных ответов API.

---

## ⚙️ Требования

- **Python 3.6** или выше.
- Установленная библиотека `requests` (для HTTP-запросов).
- Доступ в интернет (для обращения к GitHub API).
